# Evidence Review
1. Read `docs/design-system/CONTENT_CONTRACT.md`; enumerate all new/modified public claims and relationships.
2. For each claim, capture direct evidence, timeframe, method, source, approved public wording, author contribution, competing explanation, causal boundary and uncertainty.
3. Check whether a visualization visually implies something stronger than the text or sources.
4. Identify restricted content and unresolved permissions; never move private material into public assets.
5. Produce a finding ledger with statuses VERIFIED / NEEDS EVIDENCE / MUST REVISE / PRIVATE / REQUIRES HUMAN APPROVAL.
6. Block public build for unavailable provenance, unsupported quantitative shifts, invented outcomes, unapproved relationships and confidentiality risks.
