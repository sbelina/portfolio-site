## Spatial model and reproducibility

The fixture's five dimension weights (question .35, mechanism .30, methods .15, scale .10, setting .10) are explicit design hypotheses. Each component uses Jaccard overlap of authored tag sets; there is no claim that these tags/weights validly measure real investigations. The complement of weighted similarity supplies target dissimilarity. A scalar can conceal different component profiles, so the full breakdown remains inspectable.

The optimizer minimizes the complete, unit-pair-weight raw-stress objective `sum((fittedDistance - targetDistance)^2)`. Feature weights are not pair confidence or approval weights. Eight fixed seeded starts, canonical case/pair ordering, an algorithm version, iteration cap and stopping tolerance make the pinned-runtime result reproducible. The artifact records all restart diagnostics, selected stress trace, input digest, coordinates and per-pair residuals. Convergence is a numerical stopping result, not proof of global optimality.

Normalized stress is `sqrt(rawStress / sum(targetDistance^2))`; it is not estimable when that denominator is zero. Genuine zero distances remain zero rather than being separated for aesthetics. The first proof requires a complete matrix; sparse/disconnected layouts need a separate decision before global separation could be interpreted.

Only investigations are plotted. Terms, methods, evidence and outcomes cannot silently inherit a case-to-case distance model. Filtering retains the full-corpus coordinate artifact. Text/label adjustments never change point positions. A future analytical chart must use exclusively its own named-axis rules. Region inference/naming, rubric evaluation, actual corpus classification, frame controls and a finished interactive Atlas remain proposals.

The input SHA-256 binds the classification arguments, not source truth, a whole manuscript or authenticated owner approval. Source/candidate integrity and publication remain governed by existing exact-candidate contracts. The downloadable input wraps the exact arguments in an `input` field and labels the record synthetic; the optimizer can replay that field.
