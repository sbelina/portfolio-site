# Learning and facilitation — content specification, 16 November 2026

Proposed route `/learning/`. The local shell is `src/design/ProposalPage.tsx`, built only by `npm run build:fixtures`. Nothing here is published or approved.

## Purpose

Show the capability of designing conditions for other people’s understanding, and connect it to an interest in inquiry-based education. This must not recast the owner as an established schoolteacher or imply results with learners.

## Three kinds of material, kept separate

| Section | Contains | Must not contain |
| --- | --- | --- |
| Demonstrated practice | Facilitation, training, mentoring, workshop design, knowledge transfer from real work, with sanitized artifacts | Outcomes beyond what sources show |
| Transferable methods | Question framing, cognitive load, interpretation, systems mapping, creative problem solving, accessible information design, competing explanations | Claims that a method is proven effective |
| Prospective educational research | Questions about developing and assessing critical thinking, inquiry, epistemic reasoning and learner independence | Any suggestion of tested effectiveness with schoolchildren |

## Learning-design case template

Each case records:

1. Audience and their starting understanding.
2. Intended capability or learning objective.
3. Activity or resource design.
4. Participant interaction.
5. Feedback and evaluation.
6. Observed use.
7. Limitation or unresolved question.

Show authentic, sanitized artifacts where rights allow. Mark each field as documented, owner-reported or unknown.

**Preferred first case.** The Claims knowledge-development work: facilitated administrator discussions that informed reference and onboarding resources. Constraints from the [ledger](PUBLICATION-LEDGER.md) apply. In particular, keep each resource’s audience and usage evidence separate. The learning case and the investigation account must agree, and should link to each other once both are approved.

## Proposed experience: *How do we know what we know?* (untested)

1. Examine an initially plausible claim.
2. Identify the assumptions it depends on.
3. Compare at least two interpretations.
4. Define the evidence that would distinguish them.
5. Revise the original question.

**Proposed assessment criteria.** These are draft criteria, not validated:

- Names an assumption that was not stated in the claim.
- Describes evidence that could count against the preferred interpretation.
- Explains how the revised question differs from the first, and why.
- Accepts a defensible approach that differs from the facilitator’s.

The activity invites several defensible approaches. No sessions have been run, so there is no feedback and no learning gain to report. Before running it with minors, settle consent, safeguarding and data handling. Publish no participant material without permission.
