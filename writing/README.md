## Where new manuscripts belong

This application repository is public. A folder called “review” does not make its contents private. These files only copy material already present in its source.

Use the planned **private content repository** for unpublished originals and revisions, with a `writing/inbox/` collection and stable IDs. Move through review by changing editorial state rather than moving or renaming canonical files. Keep full manuscript bodies and private review notes there. Import only the approved public projection into this site's build.

Do not automatically import Library files, private poems, personal notes, or unrelated writing into this public repository. When a private source is connected, match each manuscript to its existing ID and preserve original wording and line breaks. A reviewed piece can remain unpublished indefinitely.

## Review decisions

For each piece, Sam can request edits, approve a specific candidate, defer it, or choose not to publish. Approval does not deploy. A later publish action releases the approved version; subsequent edits create a new draft while the prior live version remains available.

The current review records and page list are documents. They do not yet provide working CMS approval or Publish buttons.
